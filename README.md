# IP, PLEASE · IPを提示せよ

『Papers, Please』風のドット絵ミニゲーム。

あなたは「十月労働懸賞」に当選し、**調整局・東八区検問所**の入国審査官 Claude に任命された。仕事はただ一つ、アメリカ人を装った旅客を見破ること。

**オンラインでプレイ：<>**

- 全6日間のストーリーと2種類のエンディング。プレイ時間は約30分。セーブデータは毎日自動保存。
- スマートフォンは横画面で指を使って操作。PCではマウスで証明書をドラッグして操作。
- 完全な静的ウェブサイトで、外部リソースを一切読み込まない。リポジトリをダウンロードすれば、`index.html` をダブルクリックするだけでもプレイ可能。

## 対応言語

オリジナルに英語版が追加される前のソースから翻訳しています。<br>
画面右上の言語セレクターから切り替えられます。現在は次の5言語を収録しています。

- 日本語（`ja-JP` デフォルト）
- 简体中文（`zh-CN` オリジナル）
- English（`en-US` slop）
- 한국어（`ko-KR` slop）
- 繁體中文（`zh-TW` slop）

翻訳データは`locales/`にあり、`i18n.js`が言語の読み込みと切り替えを担当します。配布用の`assets.js`にはロケールもあらかじめ同梱されています。<br>
slopと書かれた言語はテストしていません。

## 遊び方

番号を呼ぶ → 証明書を机にドラッグする → 『憲法』と照合して検査する → スタンプを押す → 証明書を旅客に返す。

## 各日の新ルール・新ツール

| 日 | 新ルール・新ツール |
|---|---|
| 1日目 | 対象地域のIPだけを許可する |
| 2日目 | タイムゾーンと言語がIPの地域と一致していること。審問・拘束機能が登場 |
| 3日目 | アカウントカード：決済カード、請求先住所、電話番号 |
| 4日目 | X線でバックグラウンドプロセスを走査。中国語ネットスラング高速審査 |
| 5日目 | 中国資本の持ち株比率が過半数なら禁止。蒸留軍団が登場 |
| 6日目 | ジョージ兄貴・アルティメット版、そして最後の旅客 |

## ディレクトリ構成

| パス | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `main.js` | シーン切り替え、入力処理、メインループ |
| `booth.js` | 検問ブース：証明書、スタンプ、検査モード、審問、X線 |
| `events.js` | 中国語ネットスラング高速審査、蒸留軍団、チャットのアカウント停止、エンディング |
| `screens.js` | オープニング、新聞、退勤時の精算、エンディング、セーブデータ |
| `data.js` | シナリオ：各日の旅客、新聞、ランダムな旅客 |
| `docs.js` | 証明書：パスポート、端末入境カード、アカウントカード、憲法 |
| `i18n.js` / `locales/` | 多言語対応の仕組み／各言語の翻訳データ |
| `gfx.js` / `sfx.js` | ドット絵描画／効果音の合成（すべてその場で合成し、音声ファイルは使用しない） |
| `assets.js` | 事前レンダリングされた人物、背景、字形アトラス（`tools/build_assets.py` で生成。手動編集禁止） |
| `tools/` | 素材生成ツール。`pp/` は人物・背景のドット絵描画処理、`assets/fonts/` はピクセルフォント |

## 改修と素材の再生成

ゲーム内のテキストを変更した場合（新たに登場する漢字は字形アトラスへの追加が必要）、または人物の描画処理を変更した場合は、`assets.js` を再生成する。

```bash
cd tools
uv sync
uv run build_assets.py
```

ローカルでプレビューするには、リポジトリのルートディレクトリで次のコマンドを実行する。

```bash
python -m http.server
```

その後、http://localhost:8000 を開く。
